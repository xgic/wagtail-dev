# Contributing to XGIC Wagtail Dev

Thank you for contributing.

## Standards

- Multi-repo policy: https://github.com/xgic/ai
- Community health: https://github.com/xgic/ai/blob/main/docs/community-health.md
- Default CMS: [ADR-0006](https://github.com/xgic/ai/blob/main/docs/adr/0006-adopt-wagtail.md)
- Template (app start): https://github.com/xgic/wagtail

## Workflow

1. Open an issue (templates; **labels required**).
2. Branch from `main` with the issue number in the name.
3. Conventional Commits.
4. PR to `main` with labels.
5. Human review in the GitHub UI before merge.

## Public safety

Do not include private infrastructure details, private tracker IDs, or internal paths in issues, PRs, or code.
